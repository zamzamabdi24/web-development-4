# SpendWise Dashboard

SpendWise is a responsive personal finance dashboard created using HTML5 and CSS3. It displays a financial summary, spending categories, savings progress, and recent transactions using Kenyan Shilling values.

## Features

- Responsive personal finance dashboard.
- CSS Grid for the main page and card layouts.
- Flexbox for internal alignment.
- CSS custom properties for colors and reusable values.
- Responsive media queries below 768px.
- Six spending categories:
  - Food
  - Transport
  - Rent
  - Entertainment
  - Savings
  - Utilities
- Savings progress bar.
- Recent transactions section.
- Keyboard-focusable dashboard cards.
- Hover and focus effects.
- Dark theme support based on system preferences.
- Reduced-motion support.

## Technologies

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS custom properties
- CSS media queries
- Google Fonts

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Make sure `index.html` and `style.css` are in the same folder.

The stylesheet is connected through:

```html
<link rel="stylesheet" href="style.css">
```

## Responsive Design

The dashboard uses a multi-column layout on larger screens. Below 768px, the layout changes to a mobile-friendly arrangement, and below 500px, the cards use a single-column layout.
